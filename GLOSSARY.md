## Constraint

The project brief forbids reading anyone else's source code related to `calc.exe`, but allows
reading code this project decompiled from `calc.exe` itself. So far nothing has been decompiled:
behaviour was implemented from general knowledge of how a standard desktop calculator works and
from observation of its public, user-visible behaviour. If a web address is consulted in future it
**must** be added to the table above together with the reason it was read.

## Terms

| Term | Meaning |
| --- | --- |
| CE | Clear Entry: clears the number currently being typed. |
| C | Clear: resets the whole calculation. |
| MC / MR / MS / M+ / M− | Memory clear / recall / store / add / subtract. |
| Operand | A number an operator acts on. |
